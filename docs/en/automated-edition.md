## Reproduce without acquiring data

With Python 3.12 or newer, run the following commands from this repository:

```powershell
python -I scripts/dwr.py analyze
python -I scripts/dwr.py render
python -I scripts/dwr.py build-site
python -I scripts/dwr.py verify
```

The M2 adapter validates the closed schema and recomputes all distributed bytes from the canonical projection. It does not contact the producer, measured sites or a laboratory. This public replay verifies arithmetic and presentation; it cannot independently authenticate the private acquisition or establish complete coverage.
